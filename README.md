# Nederlands · Test 1.2

A small study app for Dutch (Flemish, NT2 A2) with the book *Zo gezegd 1.2*: words with de / het, plurals, adjective + e, Er staat / ligt / hangt, moet / mag / geen / niet, and the four writing tasks of the exam (SD1, SD3, SD4, SD5) with drawn pictures and an offline checker for free text.

**Open it:** https://ian-cailliau.github.io/nederlands/ — on an iPhone, open it in Safari and tap Share → Add to Home Screen.

- Progress stays on the phone; Instellingen → Synchroniseren keeps it in step between devices through a private GitHub gist (a token with the “gist” scope; the one used for the Polish app works too).
- The chat button sends feedback as an issue to this repo.
- Content lives in `content/*.json`; see `CLAUDE.md`, `docs/ADD-CONTENT.md` and `src/README.md`.
